  <name>Task 1: Add animation GDScript operations (create_animation, create_animation_library, add_keyframes, assign_animation_library)</name>

  <action>
Add 4 new operation functions and their match dispatch entries to godot_operations.gd:

**1. create_animation(params):**
- Extract: output_path, length (default 1.0), loop_mode (string: "none"/"linear"/"pingpong", default "none"), step (default 0.1), tracks (array)
- Create Animation.new(), set length, step, loop_mode (match string to Animation.LOOP_NONE/LOOP_LINEAR/LOOP_PINGPONG)
- For each track in tracks array: add_track(Animation.TYPE_VALUE), track_set_path(track_idx, track.path), then for each keyframe in track.keyframes: track_insert_key(track_idx, time, convert_json_to_godot_type(value, type_hint))
- Use ensure_res_prefix on output_path, create directory if needed (same pattern as create_shader_material), ResourceSaver.save(anim, output_path)
- Print JSON: {"success": true, "path": output_path, "track_count": N}

**2. create_animation_library(params):**
- Extract: output_path, animations (dictionary: name -> path)
- Create AnimationLibrary.new()
- For each animation_name in animations dict: load(ensure_res_prefix(path)) as Animation, check null, library.add_animation(name, anim)
- ResourceSaver.save(library, output_path)
- Print JSON: {"success": true, "path": output_path, "animation_count": N}

**3. add_keyframes(params):**
- Extract: animation_path, track_index (int, optional) OR track_path (string, optional), keyframes (array of {time, value, type})
- Load existing animation: load(ensure_res_prefix(animation_path)) as Animation, check null
- Resolve track: if track_index provided use directly; if track_path provided, iterate animation.get_track_count() checking track_get_path() for match
- For each keyframe: track_insert_key(track_idx, float(time), convert_json_to_godot_type(value, type_hint))
- ResourceSaver.save(anim, animation_path)
- Print JSON: {"success": true, "path": animation_path, "keyframes_added": N}

**4. assign_animation_library(params):**
- Extract: scene_path, node_path (to AnimationPlayer), library_name (string, e.g. "" for default), library_path (path to .tres)
- Load scene, instantiate, find_node_by_path to get AnimationPlayer node
- Verify target is AnimationPlayer: `if not target is AnimationPlayer`
- Load library: load(ensure_res_prefix(library_path)) as AnimationLibrary, check null
- target.add_animation_library(library_name, library)
- Repack and save scene (same pattern as connect_signal: PackedScene.new(), pack(scene_root), ResourceSaver.save(packed, scene_path))
- Print JSON: {"success": true, "library_name": name, "scene_path": path}

**Match dispatch entries:** Add to the existing match block in _init():

"create_animation_library":
    create_animation_library(params)

<task type="auto">
  <name>Task 2: Add tilemap GDScript operations (create_tileset, paint_tilemap)</name>
  <files>src/scripts/godot_operations.gd</files>
  <action>
Add 2 new operation functions and their match dispatch entries to godot_operations.gd:

**1. create_tileset(params):**
- Extract: output_path, texture_path, tile_width (default 16), tile_height (default 16), separation_x (default 0), separation_y (default 0), margin_x (default 0), margin_y (default 0), columns (optional), rows (optional)
- Load texture: load(ensure_res_prefix(texture_path)) as Texture2D, check null with error message
- Create TileSet.new(), set tile_size = Vector2i(tile_width, tile_height)
- Create TileSetAtlasSource.new()
- Set atlas_source.texture = texture (MUST be before create_tile -- critical ordering)
- Set atlas_source.texture_region_size = Vector2i(tile_width, tile_height)
- Set atlas_source.separation = Vector2i(separation_x, separation_y) if non-zero
- Set atlas_source.margins = Vector2i(margin_x, margin_y) if non-zero
- Auto-create tiles from grid: if columns/rows provided use those, otherwise calculate from texture.get_size() accounting for margins and separation. If texture size is (0,0) AND no columns/rows provided, log error and return failure.
- For y in range(grid_h), for x in range(grid_w): atlas_source.create_tile(Vector2i(x, y))
- tileset.add_source(atlas_source) -> capture source_id
- ResourceSaver.save(tileset, output_path)
- Print JSON: {"success": true, "path": output_path, "source_id": source_id, "grid_size": {"x": grid_w, "y": grid_h}, "tile_count": grid_w * grid_h}

**2. paint_tilemap(params):**
- Extract: scene_path, node_path, mode ("paint"/"fill"/"clear"), plus mode-specific params
- Load scene, instantiate, find_node_by_path, verify target is TileMapLayer: `if not target is TileMapLayer`
- Mode "paint": extract cells array [{x, y, source_id, atlas_x, atlas_y, alternative_tile?}], for each cell call target.set_cell(Vector2i(x,y), source_id, Vector2i(atlas_x, atlas_y), alternative_tile or 0)
- Mode "fill": extract x_start, y_start, x_end, y_end, source_id, atlas_x, atlas_y, alternative_tile (default 0). Loop y in range(y_start, y_end+1), x in range(x_start, x_end+1), call set_cell for each
- Mode "clear": extract cells array (optional). If cells is empty or not provided, call target.clear(). Otherwise for each cell call target.erase_cell(Vector2i(x, y))
- Repack and save scene (same pattern as connect_signal)
- Print JSON: for paint {"success": true, "cells_painted": N}, for fill {"success": true, "cells_filled": N}, for clear {"success": true, "cleared": "all" or N}

**Match dispatch entries:**
```gdscript
"create_tileset":
    create_tileset(params)
"paint_tilemap":
    paint_tilemap(params)
```

Follow exact coding style of existing operations. Use TileMapLayer (NOT deprecated TileMap class). Set texture BEFORE create_tile() on TileSetAtlasSource.
