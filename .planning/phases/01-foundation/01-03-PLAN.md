<objective>
Harden process execution with maxBuffer/timeout limits, implement comprehensive process tracking for zombie prevention, register SIGINT/SIGTERM signal handlers for clean shutdown, and audit all tool error responses for structured format with actionable suggestions.

Purpose: Without process hardening, large Godot output crashes the server. Without signal handlers, stopping the MCP server leaves orphaned Godot processes. Without structured errors, AI assistants get raw stderr instead of actionable guidance.

Output: A robust server that gracefully handles process limits, cleans up on shutdown, and returns helpful errors.
</objective>
