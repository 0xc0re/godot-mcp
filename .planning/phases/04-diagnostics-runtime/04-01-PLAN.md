<feature>
  <name>LSP JSON-RPC Message Framing</name>
  <files>src/lsp/protocol.ts, tests/lsp-protocol.test.ts</files>
  <behavior>
    - encodeMessage({jsonrpc:'2.0', id:1, method:'initialize', params:{}}) produces Buffer starting with "Content-Length: {N}\r\n\r\n" followed by the JSON body where N equals Buffer.byteLength of the JSON string
    - parseMessages(buffer with one complete message) returns { messages: [parsed JSON-RPC object], remainder: empty Buffer }
    - parseMessages(buffer with two concatenated messages) returns { messages: [msg1, msg2], remainder: empty Buffer }
    - parseMessages(buffer with one complete message + partial second) returns { messages: [msg1], remainder: Buffer containing partial data }
    - parseMessages(buffer with only partial header "Content-Le") returns { messages: [], remainder: original Buffer }
    - parseMessages(buffer with header but incomplete body) returns { messages: [], remainder: original Buffer }
    - encodeMessage handles UTF-8 multi-byte characters correctly (Content-Length counts bytes, not characters)
  </behavior>
  <implementation>
    Create `src/lsp/protocol.ts` exporting:

    1. `JsonRpcMessage` interface:
       ```typescript
       export interface JsonRpcMessage {
         jsonrpc: '2.0';
         id?: number;
         method?: string;
         params?: unknown;
         result?: unknown;
         error?: { code: number; message: string; data?: unknown };
       }
       ```

    2. `encodeMessage(msg: JsonRpcMessage): Buffer` — Serializes a JSON-RPC message with Content-Length framing per LSP spec.

    3. `parseMessages(buffer: Buffer): { messages: JsonRpcMessage[]; remainder: Buffer }` — Extracts complete messages from a TCP data buffer, returning any unconsumed bytes as remainder for the next `data` event.

    Implementation notes from research:
    - Header format is exactly `Content-Length: {N}\r\n\r\n` (LSP 3.17 spec)
    - Use `Buffer.byteLength(body)` not `body.length` for Content-Length (handles UTF-8)
    - Search for `\r\n\r\n` as header terminator via `buffer.indexOf('\r\n\r\n', offset)`
    - Parse Content-Length via regex `/Content-Length:\s*(\d+)/i`
    - Body starts at `headerEnd + 4` (length of `\r\n\r\n`)
    - If `bodyStart + contentLength > buffer.length`, the message is incomplete — return as remainder
  </implementation>
</feature>
