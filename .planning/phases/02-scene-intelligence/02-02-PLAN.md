  <name>Task 1: Add GDScript write operations to godot_operations.gd</name>
  <files>src/scripts/godot_operations.gd</files>
  <action>
    Extend godot_operations.gd with 3 new operations and a type conversion helper. Add to the `match operation:` block in _init():

    1. **convert_json_to_godot_type(value, type_hint: String)** helper function:
       - Match on type_hint string: "Vector2" -> Vector2(value.x, value.y), "Vector3" -> Vector3(value.x, value.y, value.z), "Color" -> Color(value.r, value.g, value.b, value.get("a", 1.0)), "bool" -> bool(value), "int" -> int(value), "float" -> float(value), default -> pass through
       - Used by modify_node_property for correct property type assignment

    2. **modify_node_property(params)** operation:
       - Load scene: `var scene = load(ensure_res_prefix(params.scene_path))`
       - Instantiate: `var scene_root = scene.instantiate()`
       - Navigate to node: handle "root/" prefix stripping, empty path = root, else get_node()
       - Convert value: `convert_json_to_godot_type(params.value, params.get("value_type", ""))`
       - Set property: `target.set(params.property_name, converted_value)`
       - Re-pack and save: `PackedScene.new().pack(scene_root)` then `ResourceSaver.save(packed, path)`
       - Print JSON result: `{"success": true, "node": ..., "property": ...}`
       - Error if scene fails to load, node not found

    3. **remove_node(params)** operation:
       - Load and instantiate scene (same pattern)
       - Navigate to target node (same path handling)
       - Guard: cannot remove root node
       - Remove: `target.get_parent().remove_child(target)` then `target.queue_free()`
       - Re-pack and save
       - Print JSON result: `{"success": true, "removed": ...}`

    4. **attach_script(params)** operation:
       - Load and instantiate scene
       - Navigate to target node
       - Load script: `var script = load(ensure_res_prefix(params.script_path))`
       - Guard: script must load successfully
       - Attach: `target.set_script(script)`
       - Re-pack and save
       - Print JSON result: `{"success": true, "node": ..., "script": ...}`

    Add all three operations to the match statement:
    ```gdscript
    "modify_node_property":
        modify_node_property(params)
    "remove_node":
        remove_node(params)
    "attach_script":
        attach_script(params)
    ```

    Follow existing patterns from create_scene/add_node for error handling (log_error + quit(1)), path handling (ensure_res_prefix), and JSON output.
  </action>
