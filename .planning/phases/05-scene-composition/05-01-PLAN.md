1. **Extract `find_node_by_path()` helper function** near the top of the file (after the logging functions, before the operation functions). This replaces the duplicated node-path resolution pattern that appears 4+ times:

```gdscript
## Resolve a node path relative to the scene root.
## Handles "root", "root/Path/To/Node", and plain relative paths.
func find_node_by_path(scene_root: Node, node_path: String) -> Node:
    if node_path == "root" or node_path == "":
        return scene_root
    var target = scene_root
    if node_path.begins_with("root/"):
        var relative_path = node_path.substr(5)
        if relative_path != "":
            target = scene_root.get_node_or_null(relative_path)
    else:
        target = scene_root.get_node_or_null(node_path)
    return target
```

Use `get_node_or_null()` instead of `get_node()` so callers can check for null and provide descriptive errors rather than getting Godot engine crashes.

2. **Add 5 new operation names to the `match` block** in `_init()`, before the `_:` default case:

```gdscript
        "connect_signal":
            connect_signal(params)
        "disconnect_signal":
            disconnect_signal(params)
        "instance_scene":
            instance_scene(params)
        "batch_set_properties":
            batch_set_properties(params)
        "manage_groups":
            manage_groups(params)
```

3. **Implement `connect_signal(params)`:**
   - Expects: `params.scene_path`, `params.source_node_path`, `params.signal_name`, `params.target_node_path`, `params.method_name`
   - Load scene with `load(ensure_res_prefix(params.scene_path))`, instantiate
   - Find source and target nodes using `find_node_by_path(scene_root, ...)`
   - If either node is null, `log_error("Node not found: " + path)` and `quit(1)`
   - Verify signal exists: `if not source.has_signal(params.signal_name)`, log error with available signals hint, quit(1)
   - Connect with CONNECT_PERSIST: `source[params.signal_name].connect(Callable(target, params.method_name), CONNECT_PERSIST)`
   - Pack and save (standard pattern: `PackedScene.new()`, `pack(scene_root)`, `ResourceSaver.save()`)
   - Print JSON result: `{"success": true, "signal": signal_name, "from": source_path, "to": target_path, "method": method_name}`

4. **Implement `disconnect_signal(params)`:**
   - Expects: `params.scene_path`, `params.source_node_path`, `params.signal_name`, `params.target_node_path`, `params.method_name`
   - Load scene, instantiate, find source and target nodes
   - Check connection exists: `if not source.is_connected(params.signal_name, Callable(target, params.method_name))`, log error "Signal not connected", quit(1)
   - Disconnect: `source.disconnect(params.signal_name, Callable(target, params.method_name))`
   - Pack and save
   - Print JSON result: `{"success": true, "disconnected": signal_name}`

5. **Implement `instance_scene(params)`:**
   - Expects: `params.scene_path`, `params.child_scene_path`, `params.parent_node_path`, optional `params.node_name`
   - Load parent scene, instantiate
   - Find parent node using `find_node_by_path(scene_root, params.parent_node_path)`
   - Load child scene: `var child_packed = load(ensure_res_prefix(params.child_scene_path)) as PackedScene`
   - If null, log error "Failed to load child scene", quit(1)
   - `var child_instance = child_packed.instantiate()`
   - If `params.has("node_name") and not params.node_name.is_empty()`: set `child_instance.name = params.node_name`
   - `parent.add_child(child_instance)`
   - CRITICAL: `child_instance.owner = scene_root` (NOT parent -- must be scene root for pack())
   - Do NOT set owner on the child instance's own children
   - Pack and save
   - Print JSON result: `{"success": true, "instanced": child_scene_path, "parent": parent_node_path, "name": child_instance.name}`

6. **Implement `batch_set_properties(params)`:**
   - Expects: `params.scene_path`, `params.operations` (array of `{node_path, property_name, value, value_type?}`)
   - Load scene, instantiate
   - **Validation pass first** (fail-fast): iterate all operations, call `find_node_by_path()` for each. If ANY node is null, log error listing the bad path, quit(1). Do NOT modify anything yet.
   - **Apply pass**: iterate all operations again, find each node, convert value using `convert_json_to_godot_type(op.value, type_hint)`, call `target.set(op.property_name, converted_value)`
   - Single pack and save at the end
   - Print JSON result: `{"success": true, "operations_applied": operations.size()}`

7. **Implement `manage_groups(params)`:**
   - Expects: `params.scene_path`, `params.node_path`, optional `params.add_groups` (array of strings), optional `params.remove_groups` (array of strings)
   - Load scene, instantiate
   - Find target node using `find_node_by_path(scene_root, params.node_path)`
   - If `params.has("add_groups")`: for each group_name in `params.add_groups`, call `target.add_to_group(group_name, true)` (second param `true` = persistent, survives pack/save)
   - If `params.has("remove_groups")`: for each group_name in `params.remove_groups`, call `target.remove_from_group(group_name)` (no error if not in group)
   - Pack and save
   - Print JSON result: `{"success": true, "node": node_path, "groups": target.get_groups()}` (get_groups returns current group list)

8. **Update existing operations** (modify_node_property, remove_node, attach_script) to use the new `find_node_by_path()` helper, replacing the duplicated inline node-path resolution blocks. This is a refactor of existing code -- behavior must not change.
