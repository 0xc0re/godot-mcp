From src/tools/scene.ts (standard tool handler pattern to follow):
```typescript
server.registerTool(
  'tool_name',
  {
    title: 'Tool Title',
    description: 'Description...',
    inputSchema: {
      project_path: z.string().describe('Path to the Godot project directory'),
      scene_path: z.string().describe('Path to scene file (relative to project, e.g., "scenes/main.tscn")'),
      // ... tool-specific params with snake_case keys ...
    },
  },
  async ({ project_path, scene_path, ... }) => {
    // 1. Validate paths
    if (!validatePath(project_path) || !validatePath(scene_path)) {
      return toolError('Invalid path', ['Provide valid paths...']);
    }
    // 2. Check project.godot exists
    if (!existsSync(join(project_path, 'project.godot'))) {
      return toolError('No Godot project found...', ['Check project_path...']);
    }
    // 3. Build camelCase params for GDScript
    const params = { scenePath: scene_path, ... };
    // 4. Execute operation
    try {
      const { stdout, stderr } = await executeOperation(ctx, project_path, 'op_name', params);
      if (stderr.includes('Failed to') || stderr.includes('[ERROR]')) {
        return toolError(`Operation failed: ${stderr}`, [...]);
      }
      return { content: [{ type: 'text' as const, text: stdout }] };
    } catch (error: unknown) {
      const msg = error instanceof Error ? error.message : 'Unknown error';
      return toolError(`Failed: ${msg}`, [...]);
    }
  },
);
```

2. **Implement 5 tools inside `registerCompositionTools()`:**

   All tools follow the standard pattern from `src/tools/scene.ts`:
   - Validate paths with `validatePath()` from `../godot.js`
   - Check `existsSync(join(project_path, 'project.godot'))`

   **Tool 1: `connect_signal`**
   - Title: "Connect Signal"
   - Description: "Connect a signal between two nodes in a Godot scene. The connection persists in the .tscn file (uses CONNECT_PERSIST). Both nodes must exist in the scene."
   - inputSchema (all z.string()):
     - `project_path` -- "Path to the Godot project directory"
     - `scene_path` -- "Path to scene file relative to project (e.g., 'scenes/main.tscn')"
     - `source_node_path` -- "Path to the node emitting the signal (e.g., 'root/Button')"
     - `signal_name` -- "Name of the signal (e.g., 'pressed', 'body_entered')"
     - `target_node_path` -- "Path to the node receiving the signal (e.g., 'root' for scene root)"
     - `method_name` -- "Name of the method to call on the target node (e.g., '_on_button_pressed')"
   - Params: `{ scenePath, sourceNodePath, signalName, targetNodePath, methodName }`
   - Operation: `'connect_signal'`

   **Tool 2: `disconnect_signal`**
   - Title: "Disconnect Signal"
   - Description: "Disconnect an existing signal connection between two nodes in a Godot scene. The connection must exist."

   - Operation: `'disconnect_signal'`

   **Tool 3: `instance_scene`**
   - Title: "Instance Scene"
   - Description: "Add a .tscn scene as an instanced child node in another scene. The instance reference (not inlined nodes) is preserved in the saved .tscn file."

     - `child_scene_path` -- z.string() "Path to the .tscn scene to instance (relative to project)"
     - `parent_node_path` -- z.string() "Path to the parent node (e.g., 'root' or 'root/Enemies')"
     - `node_name` -- z.string().optional() "Optional custom name for the instanced node"
   - Params: `{ scenePath, childScenePath, parentNodePath }` plus `nodeName` only if provided
   - Operation: `'instance_scene'`

   - Title: "Batch Set Properties"
   - Description: "Set properties on multiple nodes in a single operation. All changes are applied in one Godot subprocess call. All node paths are validated before any changes are applied."

     - `project_path` -- z.string()

   - Operation: `'batch_set_properties'`

   - Title: "Manage Groups"
