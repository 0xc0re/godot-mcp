**Implementation -- add to src/tools/runtime.ts:**

Add restart_project tool registration inside registerRuntimeTools():

```typescript
server.registerTool(
  'restart_project',
  {
    title: 'Restart Project',
    description: 'Stop the running Godot project and relaunch it. ' +
      'Use after making script changes to apply them. ' +
      'Returns confirmation with PID when the restarted project is running.',
    inputSchema: {
      project_path: z.string().describe('Path to the Godot project directory'),
      scene: z.string().optional().describe('Optional: Specific scene to run after restart'),
    },
  },
  async ({ project_path, scene }) => { ... }
);
```

Implementation logic:
1. Validate project_path (return toolError if invalid)
2. Check ctx.activeProcess (return toolError "No active Godot process to restart" if null, with suggestions: "Use run_project to start a Godot project first")
3. Kill existing process: `ctx.activeProcess.process.kill()`
4. Wait for exit with 3s timeout:
   ```typescript
   await new Promise<void>((resolve) => {
     const proc = ctx.activeProcess!.process;
     proc.once('exit', () => resolve());
     setTimeout(() => resolve(), 3000);
   });
   ```
5. Clear: `ctx.activeProcess = null;`
6. Build args: `['-d', '--path', project_path]`, add scene if provided and valid
7. Spawn new process using `spawn(ctx.godotPath, args, { stdio: 'pipe' })`, wrap with `trackProcess(ctx, ...)`
8. Set up stdout/stderr listeners (same pattern as run_project in editor.ts)
9. Assign `ctx.activeProcess = { process: proc, output, errors }`
10. Wait for first stdout data with 5s timeout (confirms engine is running):
    ```typescript
    await new Promise<void>((resolve) => {
      const timer = setTimeout(() => resolve(), 5000);
      proc.stdout?.once('data', () => { clearTimeout(timer); resolve(); });
      proc.once('error', () => { clearTimeout(timer); resolve(); });
    });
    ```
11. Return JSON result: `{ message: "Project restarted successfully", pid: proc.pid, running: !proc.killed }`

Import `spawn` from 'child_process' (add to existing imports at top of runtime.ts).
