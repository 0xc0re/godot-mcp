Create the GDScript autoload that mirrors screenshot_helper.gd architecture:

1. Constants: TRIGGER_PATH = "res://.godot/runtime_trigger", OUTPUT_PATH = "res://.godot/runtime_result.json", POLL_INTERVAL = 0.5
2. `_process(delta)`: Accumulate elapsed time, check for trigger file every 0.5 seconds. When found:
   - Read trigger file content as JSON (has `command` and `params` fields)
   - Delete trigger file immediately (before processing, to prevent re-reads)
   - Match on command: "scene_tree", "inspect_node", "get_group"
   - Write result to OUTPUT_PATH using `FileAccess.open()` with globalized path
   - `file.store_string(JSON.stringify(result))` then `file.close()`

3. `_serialize_tree(node: Node, depth: int = 0) -> Dictionary`:
   - Return `{ "name": node.name, "type": node.get_class(), "path": str(node.get_path()), "children": [] }`
   - Recurse into `node.get_children()` up to depth 10 (prevent infinite recursion)

4. `_inspect_node(node_path: String) -> Dictionary`:
   - Use `get_node_or_null(node_path)` for null-safe lookup
   - Return `{ "error": "Node not found: " + node_path }` if null
   - Iterate `node.get_property_list()`, filter by `PROPERTY_USAGE_STORAGE` flag
   - Skip properties whose name starts with underscore
   - Convert non-JSON-serializable Godot types (Vector2, Vector3, Color, Object, NodePath, etc.) via `var_to_str()` before adding to result dict
   - Return `{ "name", "type", "path", "properties": { ... } }`

5. `_get_group(group_name: String) -> Dictionary`:
   - Call `get_tree().get_nodes_in_group(group_name)`
   - Map each node to `{ "name", "type", "path" }`
   - Return `{ "group": group_name, "count": result.size(), "nodes": [...] }`

Use tabs for indentation (GDScript convention). Add file header comment explaining purpose and setup instructions (must be added as autoload to the Godot project).

Internal helper `pollForResult(projectPath: string): Promise<object>`:
