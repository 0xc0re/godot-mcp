    3. Create `src/resources/godot-resources.ts`:
    ```typescript
    import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
    import { ResourceTemplate } from '@modelcontextprotocol/sdk/server/mcp.js';
    import { readdirSync, readFileSync } from 'fs';
    import { join, relative } from 'path';
    import type { ServerContext } from '../types.js';
    ```

    - Export `registerGodotResources(server: McpServer, ctx: ServerContext): void`

    - Project path resolution: Use `process.env.GODOT_PROJECT_PATH` or `process.cwd()` as fallback. Store in a local variable. If path doesn't contain project.godot, resources list returns empty (graceful degradation).

    - Helper: `findFilesRecursive(dir: string, ext: string): string[]` — recursively find files matching extension, skip `.godot/` and `.git/` directories, return paths relative to project root.

    - **Scene resource** (`godot-scene`):
      - URI template: `godot://scene/{path}` where path is the relative .tscn path
      - list callback: enumerate all .tscn files in project, return as resources with `uri: godot://scene/${relativePath}`, `name: filename`, `mimeType: text/plain`
      - read callback: resolve `{path}` param back to absolute path, readFileSync, return as text content
      - metadata: title "Godot Scene", description "A Godot scene file (.tscn)", mimeType "text/plain"

    - **Script resource** (`godot-script`):
      - URI template: `godot://script/{path}` where path is the relative .gd path
      - list callback: enumerate all .gd files in project, return as resources
      - read callback: resolve `{path}` param back to absolute path, readFileSync, return as text content
      - metadata: title "GDScript File", description "A GDScript source file (.gd)", mimeType "text/plain"

    - URI encode special characters in paths (spaces, etc.) using encodeURIComponent on path segments.
