    - list_scripts response: `{"scripts":[{"path":"res://player.gd","class_name":"Player","methods":[{"name":"move","args":1}],"properties":[{"name":"speed","type":3}],"signals":[{"name":"died","args":0}]}],"total":1}`
    - query_class response: `{"class_name":"Node2D","parent_class":"CanvasItem","properties":[{"name":"position","type":5,"usage":4102}],"methods":[{"name":"get_position","return_type":5,"args":[]}],"signals":[{"name":"visibility_changed","args":[]}]}`

    2. Add to `src/tools/script.ts`:

    **list_scripts** tool:
    - Input schema: `project_path: z.string()`, `path_filter: z.string().optional().describe("Subdirectory to limit search, e.g. 'scripts/' (default: entire project)")`
    - Delegates to `executeOperation(ctx, project_path, 'list_scripts', { path_filter: path_filter || '' })`
    - Parses JSON from stdout using the same "find first line starting with {" pattern as validate_scripts
    - Returns formatted text with script count and per-script summary (path, class_name, method count, property count, signal count)
    - Error handling: validatePath, existsSync checks, try/catch with toolError

    **query_class** tool:
    - Input schema: `project_path: z.string()`, `class_name: z.string().describe("Godot class name to query (e.g. Node2D, CharacterBody3D)")`, `no_inheritance: z.boolean().optional().describe("If true, only return class-own members, not inherited (default: false)")`
    - Delegates to `executeOperation(ctx, project_path, 'query_class', { class_name, no_inheritance: no_inheritance || false })`
    - Parses JSON from stdout
    - Returns JSON.stringify(result, null, 2) as text content
    - Error handling: validatePath, existsSync checks, try/catch with toolError. If result contains "error" key, return toolError with the error message.

    3. Add to `src/scripts/godot_operations.gd`:

    **list_scripts** operation:
    - Takes `path_filter` param (default "res://")
    - Recursively finds all .gd files using DirAccess (reuse existing find_gd_files helper)
    - For each file: `load(file_path) as GDScript` — handle null gracefully (skip with error note)
    - Extract per script: path, class_name via `script.get_global_name()` (empty string if no class_name), methods via `script.get_script_method_list()` (filter: skip names starting with `_`), properties via `script.get_script_property_list()` (filter: `usage & PROPERTY_USAGE_SCRIPT_VARIABLE`), signals via `script.get_script_signal_list()`
    - Print JSON: `{"scripts": [...], "total": N}`
    - Add "list_scripts" to match dispatch

    **query_class** operation:
    - Takes `class_name` and `no_inheritance` params
    - Check `ClassDB.class_exists(class_name)` — if not, print error JSON and return
    - Get parent_class via `ClassDB.get_parent_class(class_name)`
    - Get properties via `ClassDB.class_get_property_list(class_name, no_inheritance)` — for each: name, type, usage
    - Get methods via `ClassDB.class_get_method_list(class_name, no_inheritance)` — for each: name, return_type (from return_val.type), args (name + type per arg)
    - Get signals via `ClassDB.class_get_signal_list(class_name, no_inheritance)` — for each: name, args (name + type per arg)
    - Print JSON: `{"class_name": ..., "parent_class": ..., "properties": [...], "methods": [...], "signals": [...]}`
    - Add "query_class" to match dispatch
