  <action>
Add 4 new GDScript operations to godot_operations.gd:

1. **add_input_action(params):** Add entries to the match dispatch block for "add_input_action". Implementation:
   - Extract action_name (string), events (Array of Dicts), deadzone (float, default 0.5)
   - Validate action_name is non-empty
   - Loop over events array, create InputEvent objects based on event.type:
     - "key": InputEventKey.new(), set physical_keycode via OS.find_keycode_from_string(event.key) if event has "key", else use event.physical_keycode directly. Also set event.keycode if present.
     - "joypad_button": InputEventJoypadButton.new(), set button_index from event.button_index (default 0)
     - "joypad_motion": InputEventJoypadMotion.new(), set axis from event.axis (default 0), axis_value from event.axis_value (default 1.0)
   - Call ProjectSettings.set_setting("input/" + action_name, {"deadzone": deadzone, "events": events_array})
   - Call ProjectSettings.save()
   - Print JSON: {"success": true, "action": action_name, "event_count": N}
   - On error, print JSON: {"success": false, "error": message}

2. **remove_input_action(params):** Add to dispatch block. Implementation:
   - Extract action_name (string)
   - Validate action_name is non-empty
   - Check ProjectSettings.has_setting("input/" + action_name), return error if not found
   - Call ProjectSettings.set_setting("input/" + action_name, null) to erase
   - Call ProjectSettings.save()
   - Print JSON: {"success": true, "action": action_name}

3. **create_shader_material(params):** Add to dispatch block. Implementation:
   - Extract shader_path, output_path, shader_params (Dict, optional)
   - Use ensure_res_prefix() on both paths (existing helper)
   - Load shader: load(shader_path) as Shader -- error if null
   - Create ShaderMaterial.new(), set .shader = loaded shader
   - Loop over shader_params dict, call material.set_shader_parameter(name, convert_json_to_godot_type(value, type_hint)) for each. Use the existing convert_json_to_godot_type helper if param_types dict is provided for type hints, otherwise pass raw values.
   - Save via ResourceSaver.save(material, output_path)
   - Print JSON: {"success": true, "path": output_path}

4. **set_shader_params(params):** Add to dispatch block. Implementation:
   - Extract material_path, shader_params (Dict), param_types (Dict, optional)
   - Use ensure_res_prefix() on material_path
   - Load material: load(material_path) as ShaderMaterial -- error if null
   - Loop over shader_params, call material.set_shader_parameter(name, convert_json_to_godot_type(value, type_hint)) for each. Use param_types[name] as type_hint if available.
   - Save via ResourceSaver.save(material, material_path)
   - Print JSON: {"success": true, "path": material_path, "params_set": count}

Add all 4 operation names to the match dispatch block before the `_:` default case, following the existing pattern.

IMPORTANT: Follow existing GDScript patterns -- use log_error() for error logging, JSON.stringify() for output, ensure_res_prefix() for paths. Reference the existing modify_project_setting and create_resource functions as templates.

**1. Extend execGodot in src/godot.ts:**

Change the `execGodot` function signature from:
```typescript
export async function execGodot(
  godotPath: string,
  args: string[],
): Promise<{ stdout: string; stderr: string }>
```
to:
```typescript
export async function execGodot(
  godotPath: string,
  args: string[],
  options?: { timeout?: number },
): Promise<{ stdout: string; stderr: string }>
```

Inside the function body:
- Add `const timeout = options?.timeout ?? EXEC_TIMEOUT;` at the top
- Replace the hardcoded `timeout: EXEC_TIMEOUT` in the execFileAsync call with `timeout`
- Update the timeout error message from `'Godot process timed out after 30 seconds'` to use the dynamic value: `` `Godot process timed out after ${timeout / 1000} seconds` ``

No other callers need updating -- existing calls pass 2 args which still works with the optional 3rd parameter.
