<objective>
Fix documented godot-mcp issues from the ballz project's CLAUDE.md:

1. **add_node scene corruption** (CRITICAL): `add_node` corrupts scenes when root scripts reference autoloads because the GDScript `load()` -> `instantiate()` -> `pack()` cycle triggers script execution in headless mode where autoload singletons don't exist. Fix by implementing add_node via TypeScript text manipulation of the .tscn file, avoiding GDScript entirely.

2. **export_project stderr blindness**: The handler destructures only `{ stdout }` from `execGodot`, ignoring `stderr`. Godot may emit error strings to stderr even with exit code 0. Fix by checking both streams.

3. **create_tileset ordering**: Already implemented correctly (texture set before `create_tile()` at line 2472 of godot_operations.gd with "CRITICAL" comment). No action needed.

4. **TileSet headless texture validation**: Already implemented (null check at line 2459 with error return). No action needed.

Purpose: Make add_node safe for real-world scenes and export_project error detection comprehensive.
Output: Fixed add_node (TypeScript-native), fixed export_project error detection, tests.
